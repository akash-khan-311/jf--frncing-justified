# JF Frncing Justified

A modern and elegant fencing service website built with **Next.js**, **Tailwind CSS**, and **Swiper.js** to showcase services, testimonials, and projects with professional animation and responsiveness.

## 🔗 Live Site

[https://jf-frncing-justified.vercel.app](https://jf-frncing-justified.vercel.app)

## 📸 Preview

![Website Preview](public/preview.jpg)

---

## 🚀 Features

- ⚡ Fully Responsive Design
- 💬 Testimonials Carousel with Smooth Animation
- 🖼️ Project Gallery Showcase
- 🧭 Marquee Section with 3D Skewed Movement
- 🧩 Reusable Components
- 📱 Mobile-First Design
- 🧑‍💼 Professionally Crafted Hero Section & CTA
